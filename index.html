Участники турнира

Вставьте FACEIT никнеймы, по одному в строке.

Формула FACEIT закрыта. CSV и загрузка через API поддерживают до 80 участников за раз. Загрузка 80 профилей может занять несколько минут. Рейтинг берём из статистики матчей, когда он есть. Для более полной истории загрузите CSV с вашими данными. API key используется только в запросе и не сохраняется.
Как считается баланс. Смешиваем текущий FACEIT level/Elo, средний FACEIT Rating из доступных матчей и объём выборки. Если по игроку нет матчевого Rating, интерфейс это показывает, а расчётная сила использует нейтральный ориентир вместо придуманного FACEIT значения.
Добавьте участников, затем загрузите их данные FACEIT или импортируйте CSV.
Распределение станет доступно после получения статистики.

FACEIT Rating — официальный показатель влияния игрока на шанс выиграть раунд. FACEIT объясняет факторы (ситуация в раунде, счёт, экономика, живые игроки), но не публикует точные веса. Балансировщик использует только фактические поля, полученные из API/импорта.

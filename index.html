Участники турнира

Вставьте FACEIT никнеймы, по одному в строке.

Формула FACEIT закрыта. CSV и загрузка через API поддерживают до 80 участников за раз. Загрузка 80 профилей может занять несколько минут. FACEIT Rating показывается только если он есть в полученных данных. При его отсутствии используется отдельная статистическая оценка; роли назначаются вручную. API key используется только в запросе и не сохраняется.
Как считается баланс. Сила: level/Elo 45%, статистическая оценка 50%, активность 5%. Оценка использует средние K/D/A, ADR, а при наличии — KAST и impact. Это прозрачный HLTV-style proxy, не точный HLTV Rating 2.0: его формула закрыта. Роли назначаются вручную и балансируются между командами.
Добавьте участников, затем загрузите их данные FACEIT или импортируйте CSV.
Распределение станет доступно после получения статистики.

FFACEIT DRAFT
Community tournament tool · CS2
Справедливый драфт для турнира

Команды, в которых есть баланс.

FACEIT Draft анализирует уровни и доступную статистику FACEIT, распределяет игроков по командам и показывает, почему получился именно такой состав.

FACEIT Developer PortalВозможности
01 / ДАННЫЕ

Профиль и матчи

Учитываются FACEIT level/Elo, K/D/A, Avg Kills, ADR и доступный FACEIT Rating. Показатель HLTV-style estimate — приближённая статистическая оценка; роли можно предложить автоматически по доступным матчевым показателям или задать вручную. Можно загрузить собственный CSV.

02 / БАЛАНС

Равные составы

Игроки распределяются по расчётной силе и выбранным ролям; алгоритм выравнивает среднюю силу и число игроков каждой основной роли. Автопредложение роли отображает статистические основания и может оставить роль неопределённой, если метрик недостаточно.

03 / ОТЧЁТ

Понятный выбор

Отчёт показывает силу команд, вклад игроков и статистического кандидата в капитаны. Результат можно скачать.

О прозрачности: HLTV-style estimate — приближённая статистическая оценка, а не точный HLTV Rating 2.0: формула HLTV закрыта. FACEIT Rating показывается только если API или импорт его предоставляют. Капитан выбирается по статистике; коммуникация и лидерские качества так не измеряются. Во время загрузки API отображается прогресс обработки профилей. Полнота истории и ролевых метрик зависит от данных, доступных через API.

FACEIT Draft — независимый community-проект для подготовки CS2-турниров. Не является официальным продуктом FACEIT.

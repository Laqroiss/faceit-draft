# FACEIT Draft — балансировщик турнира

Локальная веб-программа на Python без внешних зависимостей. Интерфейс открывается в браузере, а API-ключ отправляется только локальному серверу и не сохраняется на диск.

## Запуск

1. Установите Python 3.10 или новее.
2. В этой папке выполните `python server.py`.
3. Откройте `http://127.0.0.1:8765`.
4. Введите никнеймы FACEIT, вставьте API key и нажмите **Загрузить FACEIT**. Либо импортируйте CSV.
5. Нажмите **Распределить команды**. Результаты можно скачать CSV.

API key FACEIT создаётся в [FACEIT Developer Portal](https://developers.faceit.com/). Ключ нужен для Data API v4.

## Публичная страница проекта

Короткая страница для проекта находится в [`docs/index.html`](docs/index.html). Чтобы получить адрес GitHub Pages:

1. Опубликуйте эту папку в своём GitHub-репозитории.
2. В репозитории откройте **Settings → Pages**.
3. В **Build and deployment** выберите **Deploy from a branch**, затем нужную ветку и папку **/docs**, сохраните.
4. После публикации GitHub покажет адрес вида `https://<ваш-логин>.github.io/<имя-репозитория>/`. Его можно указать в поле Company website.

В текущей локальной папке GitHub remote ещё не настроен, поэтому опубликованного адреса пока нет.

## Импорт истории из CSV

Пример — [players-template.csv](players-template.csv). Поддерживаемые заголовки: `nickname`, `level`, `elo`, `faceit_rating`, `matches`, `win_rate`. Нужен столбец nickname; остальные поля могут быть пустыми. В рейтинге указывайте средний FACEIT Rating по матчам, а в matches — число матчей, откуда он рассчитан. Для полной истории добавьте один сводный ряд на игрока: рейтинг и объём выборки должны быть посчитаны по его матчам.

Для проверки балансировщика есть [players-80-level10.csv](players-80-level10.csv) с 80 публичными профилями из европейской таблицы лидеров. Там только уровень и Elo, без FACEIT Rating; список взят с [FPLLeaderboards](https://fplleaderboards.com/top-100), стороннего сайта, поэтому ники и ранги могут измениться. Через CSV можно распределять до 80 игроков за раз; загрузка профилей через API ограничена 40 никами за один запрос.

Приоритет API: нажмите **Импорт CSV** после загрузки профилей, если CSV должен заменить текущий набор данных.

## Модель распределения

- Расчётная сила сочетает FACEIT level/Elo (50%), FACEIT Rating (38%) и объём истории (12%). Rating нормализуется, а его вес уменьшается, если в источнике мало матчей.
- Игроки сначала распределяются змейкой по убыванию силы, затем алгоритм улучшает баланс обменами игроков между командами.
- Капитан выбирается по объёму сыгранных матчей, win rate и Rating как статистический ориентир. Эти данные не показывают коммуникацию или лидерские качества в игре.
- FACEIT не публикует формулу FACEIT Rating. Программа берёт готовое значение из матчевых данных; свои расчёты она называет расчётной силой, а не FACEIT Rating.
- Официальная пагинация API ограничивает матчевые stats диапазоном offset до 200. Поэтому API-режим может охватить только часть матчей. Для большего/полного покрытия используйте CSV со своей историей. Отсутствующий FACEIT Rating не подменяется придуманным значением.

## Технологии

Python standard library (`http.server`, `urllib`) + встроенный HTML/CSS/JavaScript. Внешние пакеты не требуются.
